# Netflix Movies Data Analysis

## Overview
This project performs Exploratory Data Analysis (EDA) on a movie dataset to uncover trends in genres, ratings, popularity, and release patterns.

The goal is to derive meaningful insights that can help understand audience preferences and content trends.

---

## Objectives
- Analyze distribution of movie genres  
- Explore relationship between popularity and ratings  
- Identify yearly release trends  
- Perform data cleaning and preprocessing  

---

## Tech Stack
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  

---

## Dataset
- File: `mymoviedb.csv`  
- Contains movie-related attributes such as genre, ratings, popularity, and release date  

---

## key Insights
- Certain genres dominate the dataset  
- Popularity and ratings show weak correlation  
- Movie releases vary significantly across years
